# Промпты для роликов-демонстраций

Один файл на упражнение: `NN-<visual>.md`, где `<visual>` — ключ из `data.js`. Всего 24 ролика.

## Два режима генерации (Grok Imagine Video 1.5, MCP `grok-imagine`)

| Режим | Когда | Параметры вызова |
|-------|-------|------------------|
| **image-to-video** | стоя лицом, нужна идеальная петля (ролик 01 «walk») | `image` = `last_frame` = стартовый кадр 4:3 |
| **reference-to-video** | все остальные, включая позы лёжа и на четвереньках | `reference_images` = [лист персонажа, нужный ракурс], в промпте `<IMAGE_1>`, `<IMAGE_2>` |

Режим референсов не требует готового кадра в нужной позе, поэтому подходит для «моста», «жука», «кошки» и т. п. Ограничения: максимум 720p, `last_frame` не используется, петля обеспечивается текстом промпта («starts and ends in the same pose») и проверяется по первому/последнему кадру.

Общие настройки: 4:3 (в режиме референсов пропорции задаются параметром, в image-to-video берутся от стартового кадра), 720p, `generate_audio=false`, статичная камера, ролик начинается и заканчивается в одной позе.
Сервер стоимость генерации не отдаёт; считаем количество клипов и секунд.

Входные картинки сначала копируются в `inbox` медиапапки сервера (`MEDIA_ROOT/inbox`), в вызов передаются имена файлов.

## Проверка и сжатие

1. Контактный лист: `ffmpeg -i clip.mp4 -vf "fps=3,scale=320:-1,tile=5x3" -frames:v 1 sheet.png`.
2. Петля: `ffmpeg -i first.png -i last.png -lavfi ssim -f null -` (хорошо ≥ 0,95).
3. Сжатие: `tools/encode-video.sh clip.mp4 <visual>` → `assets/video/<visual>.mp4` (H.264) и `.webm` (VP9). Для длинных клипов при размере > 1 МБ поднять `CRF_MP4` / `CRF_WEBM`.
