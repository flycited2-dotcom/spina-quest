# Ролики-демонстрации: как будем делать

Цель: короткие зацикленные ролики (3–6 с) для каждого упражнения с Демонстратором в стиле референсов, чтобы ребёнок видел движение, а не статичную позу.

## Что можно сделать без внешних сервисов (уже в репозитории)

1. **Анимированные схемы** — SVG с морфингом поз (SMIL) есть для всех 24 упражнений. Работают везде, весят 0 КБ.
2. **CSS-«оживление» статичной картинки** — лёгкое дыхание/покачивание (`animation: hover`) уже применено к Рико. Для поз это добавляет жизни, но не показывает движение.
3. **Покадровые ролики из 2–4 ключевых поз** (например «руки вниз → руки в стороны»): ключевые кадры кладутся в `assets/frames/<visual>/01.png…`, а склейка с плавным переходом делается в браузере (CSS `@keyframes` с `opacity`), либо собирается в WebM через Chromium `MediaRecorder` (скрипт можно добавить по аналогии с `tools/crop.js`). Ключевые кадры при этом нужно сгенерировать — см. п. «Генерация».

Ограничение: без модели генерации видео нельзя «нарисовать» промежуточные фазы движения из одной картинки. Перекрёстное растворение двух поз выглядит как призрак, поэтому для настоящих роликов нужен п. «Генерация».

## Генерация (нужна модель картинок/видео)

Два пути, оба совместимы с текущей архитектурой (`POSE_IMAGES` → путь к файлу; для видео добавим `POSE_VIDEOS` и тег `<video muted loop playsinline>`):

- **Кадры → ролик.** Сгенерировать 2–4 ключевые позы image-to-image по референсу `assets/art/sheet-character.png` (промпт в `VISUAL_STYLE.md`), затем image-to-video «плавное движение из позы А в позу Б, статичная камера, чистый фон, петля». Результат — MP4/WebM 720p, 3–6 с, ≤ 1 МБ.
- **Сразу видео.** Text/image-to-video с референсным персонажем: «мальчик выполняет упражнение "птица-собака" на синем коврике, медленно, вид сбоку, зацикленное движение, статичная камера».

В этой сессии подключён коннектор генерации изображений и видео (Higgsfield). Если решите использовать его, я могу сгенерировать первые 3–5 роликов по референсам прямо здесь; это тратит кредиты вашего аккаунта, поэтому делаю только по вашей команде.

## Требования к роликам

- Формат: MP4 (H.264) + WebM (VP9) для Android WebView и PWA; 720×720 или 960×720; 24 к/с; без звука.
- Петля: первая и последняя фаза совпадают, чтобы `loop` не дёргался.
- Фон: чистый светлый или коврик, без текста и логотипов.
- Скорость: медленная, ~1 повтор за 3–4 с (ребёнок повторяет вслед).
- Имена файлов: `assets/video/<visual>.mp4`, где `<visual>` — ключ из `data.js`.

## Порядок внедрения

1. Сгенерировать ролики для 8 базовых упражнений: ходьба, кошка, жук на спине, мост, птица-собака, баланс, полуприсед, дыхание лёжа.
2. Добавить в `data.js` карту `POSE_VIDEOS` и в `app.js` показ `<video>` с фолбэком на картинку и схему.
3. Проверить на телефоне (автозапуск видео требует `muted playsinline`).
