# Визуальный стиль и ассеты

Стиль приложения строится вокруг двух персонажей:

- **Демонстратор** — мальчик в бирюзовой футболке, тёмно-синих шортах и леггинсах, кроссовки с бирюзовыми вставками. Показывает упражнения.
- **Рико** — летающий робот-компаньон (белый корпус, бирюзовые и жёлтые детали, экран-лицо с эмоциями). Говорит с ребёнком, подсказывает, радуется.

Палитра интерфейса (см. `:root` в `styles.css`): небесно-голубой фон, белые карточки, синий `#2f7be6`, бирюзовый `#1cb8d8`, жёлтая кнопка старта `#ffc531`, зелёная кнопка «дальше» `#2fc58a`, текст тёмно-синий `#1f3b63`. Заголовки — Marmelad (рукописный, кириллица), текст — Nunito.

## Где лежат картинки

| Папка | Что там | Используется |
|-------|---------|--------------|
| `assets/art/` | Исходные референсы: 8 ракурсов мальчика, лист персонажа, лист композита, 3 макета экранов (PNG, до 900px) | как референс для генерации новых картинок и роликов; приложением не загружается |
| `assets/poses/` | Позы демонстратора без фона (WebP, прозрачные) | экран упражнения, библиотека, онбординг, карта |
| `assets/rico/` | Рико: большой, 4 эмоции (wink, think, laugh, love), домашний с фоном | облачка, отсчёт, финал, главная |
| `assets/scenes/` | Сцены с фоном: bird-dog, cobra, high-five | экран упражнения (Птица-собака), финал |

Соответствие «упражнение → картинка» задаётся в `data.js` → `POSE_IMAGES` (ключ `visual`). Если картинки нет, рисуется анимированная схема (SVG).

Ещё нет картинок для: ходьба, круги плечами, дыхание лёжа, кошка, повороты сидя, скольжение по стене, жук на спине, ягодичный мост, упор в стену, баланс, отведение ноги, полуприсед, сидя на стуле, подъём рук, встать со стула, растяжка бедра сидя. Сцена `cobra.webp` есть, но такого упражнения в программе пока нет.

## Инструменты (`tools/`)

- `crop.js` — обрезка и масштабирование через Chromium (canvas). Задания — JSON-массив `{src,out,x,y,w,h,maxH|maxW,webp}`.
- `unbg.js` — удаление светлого фона заливкой от краёв + мягкий край + обрезка по содержимому. `node tools/unbg.js in.png out.webp 14` (третий аргумент — допуск, 8–16).
- `e2e.js` — автотест приложения со скриншотами.

Запуск в этом окружении: `PW_MODULE=/opt/node22/lib/node_modules/playwright PW_EXEC=/opt/pw-browsers/chromium-1194/chrome-linux/chrome node tools/crop.js jobs.json`. Локально достаточно `npm i playwright` и `npx playwright install chromium`.

## Как добавить новую позу

1. Сгенерировать картинку в том же стиле (референсы: `assets/art/sheet-character.png`, промпт ниже).
2. `node tools/unbg.js new.png assets/poses/<visual>.webp 14`.
3. В `data.js` → `POSE_IMAGES` добавить `<visual>: 'assets/poses/<visual>.webp'`.
4. В `sw.js` добавить путь в `ASSETS` и поднять `CACHE_VERSION`.

Промпт-основа для генерации (любая модель картинок, image-to-image по референсу):
«3D-стилизованный мультяшный мальчик 8–10 лет, каштановые волнистые волосы, большие карие глаза, бирюзовая спортивная футболка с белыми швами, тёмно-синие шорты с бирюзовой вставкой поверх тёмно-синих леггинсов до икры, бело-серые кроссовки с бирюзой; поза: <описание упражнения>; вид <спереди/сбоку/3/4>; чистый светло-голубой фон, мягкий свет, Pixar-подобный рендер, полный рост, без текста».
