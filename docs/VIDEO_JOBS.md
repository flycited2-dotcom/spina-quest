# Задания на генерацию роликов (Grok Video 1.5 через Higgsfield)

Модель: `grok_video_v15` (xAI), image-to-video по стартовому кадру + референсы персонажа.
Стоимость: 22,5 кредита за клип 5 с 720p (проверено 30.09.2026). Общие настройки: 5 с, 720p,
статичная камера, чистый светло-голубой фон, без текста, медленное движение, петля.

Референсы персонажа для каждого задания: `assets/art/sheet-character.png`, `assets/art/boy-front.png`.

Итого 8 клипов × 22,5 = 180 кредитов. После генерации: скачать MP4, положить в `assets/video/<visual>.mp4`,
добавить `POSE_VIDEOS` в `data.js` и показ `<video muted loop playsinline>` в `app.js` (см. VIDEO_PIPELINE.md).
